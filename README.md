# VÉRITÉ STUDIO — Editorial Fashion Storefront

A minimalist luxury clothing brand web application built with **React**, **Vite**, **Tailwind CSS**, and **Lucide React**.

## Quick Start in VS Code

1. Unzip `verite-studio-react.zip` and open the `verite-studio` folder in **VS Code**.
2. Open the integrated terminal (`Ctrl + ~` or `Cmd + ~`).
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Build for Production
```bash
npm run build
npm run preview
```
